## Lessons Learned

Through this project, I learned:

- How to create multiple HTML pages.
- How to connect pages using navigation links.
- How semantic HTML improves website structure.
- How to connect CSS files to HTML documents.
- How to create accessible forms using labels.
- How to use required attributes for form validation.
- How to make layouts responsive using CSS media queries.
- How to use GitHub to manage and publish projects.

Some challenges I experienced include:

I addressed these challenges by practising, testing my code and reviewing the structure of my project.
