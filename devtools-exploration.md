## 1. Introduction

Browser Developer Tools (DevTools) are tools built into web browsers that help developers inspect, test and debug websites.

I explored the browser Developer Tools to understand how websites are structured and how errors can be identified.

## 2. Tools Explored

### Elements Panel

The Elements panel allows developers to inspect HTML elements and modify page content temporarily.

### Styles Panel

The Styles panel shows the CSS rules applied to HTML elements. It allows developers to test changes to colours, spacing, fonts and layouts.

### Console Panel

The Console displays JavaScript errors, warnings and messages. It helps developers identify problems in their code.

### Network Panel

The Network panel shows resources loaded by a website, including HTML, CSS, JavaScript and images.

### Lighthouse

Lighthouse audits a website for performance, accessibility, best practices and search engine optimization.

## 4. What I Learned

I learned that Developer Tools are important for finding errors and improving websites.
