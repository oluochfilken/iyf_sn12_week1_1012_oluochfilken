## 1. Introduction

Accessibility means designing websites that can be used by people with different abilities and different ways of accessing information.

The aim of this project is to make my portfolio easier to understand and navigate.

## 2. Accessibility Improvements

1. Added the HTML language attribute.
2. Used semantic HTML elements.
3. Added descriptive page titles.
4. Added navigation labels.
5. Used headings in a logical order.
6. Added labels connected to form inputs.
7. Added required attributes to form fields.
8. Added visible keyboard focus styles.
9. Used readable text and contrasting colours.
10. Added descriptive meta descriptions.
